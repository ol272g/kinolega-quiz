# KinOlega Quiz — сайт-справочник

Статический сайт с архивом игр, турнирными таблицами и рейтингом игроков.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Весь сайт: вёрстка, стили и скрипты |
| `assets/kinolega-intro.mp4` | Видео-заставка главной страницы (без звука, 10 с, по кругу) |
| `assets/kinolega-intro-poster.jpg` | Первый кадр видео: виден, пока видео грузится или если оно не запустилось |
| `assets/kinolega-bg.jpg` | Фон разделов (всё, кроме главного экрана), облегчённая копия `Фон пустой.png` |
| `assets/og-cover.jpg` | Картинка превью, когда ссылку на сайт присылают в Telegram, VK и т.п. (1200×630) |
| `assets/data.js` | Сохранённая копия данных из Google Таблицы (обновляет `update-data.py`) |
| `assets/logo-wordmark.png` | Логотип с прозрачным фоном — шапка, переход, картинка «Поделиться» |
| `assets/logo-reel.png` | Бобина из логотипа — основа иконок |
| `assets/favicon-32.png`, `assets/icon-512.png` | Иконка во вкладке браузера |
| `assets/apple-touch-icon.png` | Иконка, если сайт добавить на экран «Домой» на iPhone |
| `update-data.py` | Обновляет сохранённую копию данных из Google Таблицы |

## Как открыть

Двойной клик по `index.html`. Всё работает офлайн, кроме одного: браузер
запрещает локальному файлу обращаться к Google Таблице, поэтому в шапке
будет надпись «Локальная копия» и данные будут те, что сохранены внутри файла.

## Как обновить данные

**Вариант 1 — выложить сайт в интернет.** На хостинге (GitHub Pages, Netlify,
любой обычный хостинг) сайт сам подтягивает таблицу при каждой загрузке,
в шапке загорается зелёное «Данные из таблицы», а кнопка ↻ рядом обновляет
их вручную. Ничего делать не нужно — достаточно вести таблицу как обычно.

**Вариант 2 — обновить локальную копию.** Запустите в этой папке:

```bash
python update-data.py
```

Скрипт скачает свежие данные, перезапишет `assets/data.js` и обновит метку версии
в `index.html`, чтобы браузеры не показали старую копию из кэша.

> Таблица должна оставаться открытой на просмотр по ссылке
> (Настройки доступа → «Все, у кого есть ссылка» → Читатель).

## Публикация

Сайт опубликован на GitHub Pages: **https://ol272g.github.io/kinolega-quiz/**
Репозиторий: https://github.com/ol272g/kinolega-quiz

Всё делает файл `.github/workflows/deploy.yml`:

- **изменили сайт и отправили на GitHub** — через 1–2 минуты он опубликован;
- **каждые 4 часа** GitHub сам забирает свежие данные из Google Таблицы
  и, если что-то изменилось, обновляет сайт;
- **обновить вручную прямо сейчас** — любой из способов:
  1. откройте https://github.com/ol272g/kinolega-quiz/actions/workflows/deploy.yml,
     нажмите **Run workflow** → **Run workflow** (работает и с телефона);
  2. на этом компьютере дважды щёлкните `update-site.bat`.

Что стоит знать:
- расписание GitHub иногда запускается с опозданием на 10–30 минут — это нормально;
- если в репозитории 60 дней не было изменений, GitHub приостанавливает запуски
  по расписанию и присылает письмо; включается кнопкой **Enable workflow** на той же странице;
- если запуск упал (например, Google Таблица была недоступна), на сайте остаются
  прошлые данные — ничего не ломается.

Исходники (`лого.jpg`, заставка, фон, оригинал видео) в репозиторий не попадают —
они перечислены в `.gitignore`.

## Откуда берутся данные

Таблица `1D11oDpDLMaRFFTeLwWPOMJ49x8ZVEXSqzyxZsXJf280`, листы:

| Лист | Раздел сайта |
|---|---|
| `Games` | Вкладка «Игры»: игры группируются по паре `Paket` + `#Game` |
| `Rating` | Вкладка «Рейтинг» и карточки игроков |
| `KinOlega_2026` | Вкладка «Турнир» → «Год 2026» |
| `Зима_2026`, `Весна_2026`, `Лето_2026` | Вкладка «Турнир» → сезоны |

Места в таблице каждой игры считаются по колонке `Points` (по убыванию).

На вкладке «Турнир» есть блок **«Как считается рейтинг турнира»** по
[гайду](https://telegra.ph/Kak-schitaetsya-rejting-v-turnire-Polnyj-gajd-02-14-4):
номинальные очки → взвешенные → игровой рейтинг `(Номинал + 3 × Взвешенные × 1000) ÷ 4`
→ турнирный рейтинг (среднее по сезонам с учётом числа игроков, минус штраф).
Пример в блоке считается на реальных числах лидера. После 16-го места в годовой
таблице — граница плей-офф.

На вкладке «Турнир» у каждого сезона под таблицей есть раскрывающийся блок
**«Полная статистика сезона»** — все колонки листа и все вопросы Q1…Q63.
В ячейке — очки игрока за вопрос, чем ярче фон — тем больше вес вопроса
(из весов складываются `wОчки`), «·» — вопрос не взят, внизу — сколько процентов
игроков взяли вопрос. Вопросы подписаны группами по пять.

Два вида ячеек (выбор запоминается): **«Как в таблице»** — очки за вопрос и мелко
взвешенные очки, как в Google Таблице (`300 ⁰⋅⁴⁵`), и **«Только очки»** — компактно.
Кнопка **«На весь экран»** разворачивает статистику поверх страницы (где браузер
позволяет — в настоящий полноэкранный режим); закрыть — «Свернуть» или Esc.
Колонки `tОчки` и `Штраф` показываются ровно так, как они лежат в таблице.

### Когда появится осенний сезон

1. Добавьте лист `Осень_2026` с такими же колонками, как у `Зима_2026`.
2. В `index.html` найдите строку `seasons:['Зима_2026','Весна_2026','Лето_2026']`
   и допишите туда `'Осень_2026'`.
3. То же самое в `update-data.py` — переменная `SEASONS` вверху файла.

Кнопка «Осень 2026» на вкладке «Турнир» перестанет быть неактивной сама.

## Как заполнить расписание

Проще всего — прямо в Google Таблице (той, где считается рейтинг). Создайте лист
**«Расписание»** с колонками:

| Дата | Время | Название | Место | Примечание | Ссылка |
|---|---|---|---|---|---|
| 04.10.2026 | 19:00 | Осень#01_01 | Бар «Кадр» | Регистрация открыта | https://t.me/... |

Обязательны «Дата» и «Название», остальное можно оставлять пустым. Сайт показывает
только игры с сегодняшней даты и дальше; прошедшие строки удалять не нужно.
Ссылка работает, только если начинается с `http://` или `https://`.
Расписание попадёт на сайт при ближайшем автообновлении или по кнопке «Обновить».

Если листа нет, можно по-старому вписать игры в код: в `index.html` найдите
`const SCHEDULE = [];` и заполните список:

```js
const SCHEDULE = [
  { date:'2026-10-04', time:'19:00', title:'Осень#01_01',
    place:'Бар «Кадр»', note:'Регистрация открыта', url:'https://t.me/...' },
];
```

Вкладка «Расписание игр» сама заменит заглушку на карточки игр.
Поля `note` и `url` необязательные.

## Видео-заставка

Сайт открывается полноэкранным видео и четырьмя кнопками: **Игры**, **Турнир**,
**Рейтинг**, **Расписание игр**. Кнопка открывает раздел и плавно прокручивает к нему.
Под кнопками — число игр, сезонов и игроков, они пересчитываются из данных сами.

- Видео всегда без звука и крутится по кругу.
- Кнопка ⏸ в правом верхнем углу останавливает его и запускает снова.
- Когда страницу пролистали ниже или переключились на другую вкладку браузера,
  видео встаёт на паузу — не расходует батарею.
- Видео начинает загружаться только после того, как загрузилась сама страница,
  чтобы не отнимать канал у текста и шрифтов.
- Видео само не запускается и не качается, если в системе включено «уменьшить
  движение», на телефоне включена экономия трафика, телефон сообщает, что сидит
  на мобильном интернете, или сеть совсем медленная (2G). Тогда видна обложка,
  запустить можно кнопкой.

### Как заменить видео

1. Экспортируйте ролик в MP4 (H.264), желательно без звука.
   В настройках экспорта включите **Web Optimized / Fast Start** — тогда видео
   начинает играть сразу, не дожидаясь загрузки всего файла.
2. Положите его в `assets/` под именем `kinolega-intro.mp4`.
3. Сохраните первый кадр как `assets/kinolega-intro-poster.jpg`.

Сейчас ролик весит 4,9 МБ. Для фона на 10 секунд с мобильного интернета
комфортно до 3–5 МБ: 1920×1080 при 2–3 Мбит/с или 1280×720 при 1,5–2 Мбит/с.

## Графики

- **Игры** — число игр по месяцам; нажатие на месяц оставляет только его игры.
- **Турнир → Год** — «Гонка сезонов»: места топ-10 годового зачёта в каждом сезоне.
- **Рейтинг** — как менялся рейтинг топ-10 от пакета к пакету.

Наведите курсор или нажмите на имя в легенде, чтобы подсветить линию игрока.

## Рекорды и истории

Во вкладке «Рейтинг» под графиком — рекорды, пересчитываются из данных сами:
серия побед подряд, рекорд очков за игру, взлёт рейтинга за игру, самый плотный
финиш, больше всего побед и игр, рост рейтинга за всё время и «взял то, что не взял
никто» (вопросы, которые в своём сезоне взял только один игрок). Имена и игры
открывают карточки.

## Переход «киноплёнка»

Кнопки главного экрана открывают раздел через переход: отсчёт 3-2-1, кадры плёнки,
вспышка, название раздела. При включённом «уменьшить движение» перехода нет —
раздел открывается сразу.

**Звук перехода** сейчас выключен. Чтобы добавить свой:

1. Сгенерируйте короткий звук (около 1,5 с), например в
   [ElevenLabs Sound Effects](https://elevenlabs.io/sound-effects) или
   [Stable Audio](https://stableaudio.com), и сохраните как MP3.
2. Положите файл в `assets/sounds/`.
3. В `index.html` найдите `const TRANSITION_SOUND = '';` и впишите путь:
   `const TRANSITION_SOUND = 'assets/sounds/projector.mp3';`

Рядом с паузой видео сама появится кнопка, которой звук можно выключить.

## Курсоры

При наведении мышью на кнопки главного экрана и вкладки курсор меняется:
**Игры** — ведёрко попкорна, **Турнир** — статуэтка, **Рейтинг** — калькулятор,
**Расписание** — календарь. На телефонах и планшетах курсора нет, там ничего не меняется.

## Фото игроков

Показываются в карточке игрока и на картинке «Поделиться». **Только с согласия
игрока** — лучше, чтобы фото присылали сами (форма или бот в канале).

1. Квадратное фото от 400×400 (JPG), положите в `assets/players/`.
2. В `index.html` найдите `const PLAYER_PHOTOS = {};` и допишите:

```js
const PLAYER_PHOTOS = {
  'Карим Кадырбаев': 'karim-kadyrbaev.jpg',
};
```

Имя — точно как в таблице. Без фото показываются инициалы. Контакты игроков
на сайт не выкладывайте: всё, что лежит в `index.html`, видно любому через просмотр кода.

## Дизайн

**Шрифты:** Oswald — узкий плакатный для заголовков, Manrope — для текста и цифр
(цифры в таблицах моноширинные). Подключаются с Google Fonts, у обоих есть кириллица.

**Палитра — пять цветов**, остальные оттенки только их смеси:

| Цвет | HEX | Где |
|---|---|---|
| Ночь | `#000A20` | фон |
| Синий | `#0B1A40` | карточки, шапки таблиц |
| Золото | `#ECB024` | акценты, кнопки, 1-е место |
| Крем | `#F6ECD6` | текст, 2-е место |
| Бирюза | `#6FA8A8` | второй акцент из видео, 3-е место, рост рейтинга ▲ |

**Детали интерфейса** (приёмы с [21st.dev](https://21st.dev/community/components)):
- у кнопок на главной и карточек игр светящаяся рамка идёт за курсором;
- числа на главной и в сводке турнира один раз «докручиваются», когда появляются на экране;
- над таблицами турнира — сводка плиткой (бенто): для года и для каждого сезона своя;
- в переключателе «Год / Зима / Весна / Лето» золотая подложка переезжает к выбранному пункту.

**Шкалы.** Размеры текста — 11, 12, 13, 14, 15, 16, 18, 20, 24, 28, 34 px
(плюс резиновые заголовки). Скругления — 4 ступени: `--r-sm` 6, `--r-md` 10,
`--r-lg` 16, `--r-xl` 24 px. Тени — `--shadow-1` (мелкие элементы), `--shadow-2`
(карточки, окна), `--shadow-glow` (золотые кнопки). Длительности — `--t-fast`,
`--t-mid`, `--t-slow`. Новые элементы стоит собирать из этих значений.

Смысл никогда не передаётся только цветом: у изменения рейтинга есть стрелка ▲/▼,
у мест — номер.

Фактура — киноплёнка: статичное зерно поверх видео и перфорация на карточках-билетах.
Без интернета подставятся системные — сайт не сломается, только станет проще.

## Экраны

Проверено на ширинах 320, 375, 414, 500, 600, 700, 768, 900, 1024, 1280, 1440 px
и в альбомной ориентации телефона — горизонтальной прокрутки нет нигде,
включая обе всплывающие карточки.

На узких экранах таблицы не уезжают вбок, а сворачиваются: лишние колонки
уходят второй строкой под именем игрока (например «12 игр · 10 побед»
в рейтинге или «44 ответа · Winter_07_2026» в сезоне). На планшете и компьютере
все колонки возвращаются на место. Кнопки и чипы на сенсорных экранах
не меньше 44 px.

Все анимации отключаются, если в системе включено «уменьшить движение»
(Windows: Параметры → Специальные возможности → Визуальные эффекты).
